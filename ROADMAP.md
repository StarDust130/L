## 🧠 Engineering Principles

> **Simple. Reliable. Useful.**

1. 🎯 Solve real problems first.
2. 🧩 Use normal code for rules.
3. 🤖 Use AI only where judgment is needed.
4. 🛡️ Never trust AI output without validation.
5. 💾 Store important data safely.
6. 📈 Make every automation observable.
7. 🔒 Protect user data and secrets.
8. 🧪 Test behavior, not implementation.
9. 🚀 Add complexity only when necessary.
10. ❤️ Build something people actually want.

## 🌟 Vision

L isn't another job board.

It's a personal AI career agent that quietly works in the background—searching, filtering, understanding, and recommending the best opportunities while you focus on becoming a better developer.

Instead of opening ten different websites every day, you simply open Telegram and find the jobs worth applying to.
